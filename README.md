# 🎵 VK Music Downloader (macOS & Windows)

Универсальный загрузчик музыки из ВКонтакте с встроенным плеером. Скачивает треки в максимальном качестве (320 kbps), поддерживает поиск по базе ВК, воспроизведение локальных файлов и автоматические обновления.

## 🚀 Основные возможности
- **Загрузчик ВК:** Скачивание плейлистов и поиск по всей базе ВКонтакте.
- **Плеер:** Встроенный аудиоплеер на базе VLC с поддержкой перемотки, цикла, отображения битрейта и тегов.
- **Управление файлами:** Возможность удалять треки прямо из плеера.
- **Авторизация:** Вход по логину/паролю (с поддержкой 2FA по звонку) или вставка готового токена.
- **Автообновления:** Встроенная проверка новых версий на GitHub.

## 📦 Установка

### macOS
1. Скачайте файл `VKMusicDownloader.dmg` из раздела **Releases**.
2. Откройте образ и перетащите `VKMusicDownloader.app` в папку `/Applications`.
3. **Важно:** Так как приложение не подписано сертификатом Apple, при первом запуске macOS может его заблокировать. Откройте Терминал и выполните:
   ```bash
   sudo xattr -rd com.apple.quarantine "/Applications/VKMusicDownloader.app"
